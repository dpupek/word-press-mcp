# WordPress MCP Server v1

## Big idea
Create a generator-driven MCP server for WordPress REST APIs that exposes broad endpoint coverage, strong validation, smart error guidance, and higher-level workflow tools for publishing tasks.

## Success criteria
- Route-derived endpoint tools are generated and committed.
- Mutating calls require explicit confirmation in safe mode.
- Common publishing workflows are available as guided tools.
- Help resources teach agents how to use the server safely and effectively.
